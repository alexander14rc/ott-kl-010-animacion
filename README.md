# Animación OTT KL 010

Animación de capacitación sobre el uso del OTT KL 010 con cinta de 100 m:
medición del nivel de agua con el sensor normal y de la profundidad del pozo con el sensor de fondo.

Es una sola página HTML, sin dependencias externas: `index.html`.

El nivel de 12,46 m y el fondo de 23,84 m son valores de ejemplo.
